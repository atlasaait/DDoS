# DDOS

# 1. Use an avalible target IP

Find a private address IP if you want to DDoS using the network or find a public IP address if you want to DDoS using the TCP protocol

# 2. Use an avalible target port

You can use Nmap (for Windows or Linux it doesn't matter) and scan opened and avalible ports (be careful, proxies may block you!).
Then you will have to target it (80 for http, 3306 for MySQL by default..etc)

# 3. Enter a number of connections

If your CPU is able to open a lot of connections, then you can open about 100k. But avarage of computers can open approximately 65k.
